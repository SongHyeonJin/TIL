##  Kafka 실행 중 "Shutdown broker because all log dirs have failed" 에러 해결

### ⚠️ 문제 상황
오늘 Kafka를 실행하려고 했는데, 아래와 같은 에러 메시지가 계속 발생했다.
``` bash
ERROR Shutdown broker because all log dirs in C:\tmp\kafka-logs have failed
```
또한 다음과 같은 경고도 같이 출력됨
```bash
WARN Stopping serving logs in dir C:\kafka-logs (kafka.log.LogManager)
```
그리고 브로커 ID 0번과 관련된 충돌 오류도 발생
```bash
org.apache.zookeeper.KeeperException$NodeExistsException: KeeperErrorCode = NodeExists
    at org.apache.zookeeper.KeeperException.create(KeeperException.java:126)
    ...
    at kafka.zk.KafkaZkClient.registerBroker(KafkaZkClient.scala:106)
```

### ✅ 원인 분석
Kafka는 내부적으로 로그 데이터를 저장하는 디렉터리를 사용하는데,
`server.properties`에 설정된 `log.dirs` 경로에 문제가 있을 경우 Kafka는 정상적으로 실행되지 않는다.

이번 에러는 내가 Kafka로 동작방식 확인하며 테스트로 한 번 Zookeeper 연결 -> Kafka 연결 -> Topic 생성 -> Producer 메시지 전송 -> Consumer 메시지 반환을 다 확인한 후 Zookeeper와 Kafka를 정상 종료하지 않고 창을 강제 종료해서 발생한 거 였다.

- 그로 인해
    - `log.dirs`에 해당하는 디렉터리가 잠긴 상태로 남음
    - Zookeeper 내부의 `/brokers/ids/0` 정보가 남아 브로커 ID 충돌 발생

### 🛠️ 해결 방법
1. **Kafka와 Zookeeper 완전 종료**
- 작업 관리자에서 프로세스를 강제 종료했다. 프로세스는 아래와 같다.

2. 아래 **디렉터리 모두 삭제**(Kafka 로그와 Zookeeper 메타데이터가 저장된 폴더)
```bash
C:\tmp\kafka-logs
C:\tmp\zookeeper
```
3. `server.properties`에서 로그 디렉터리 경로 확인 및 설정
```bash
log.dirs=\tmp\kafka-logs
```
- Zookeeper는 따로 안만들어도 되지만 kafka-logs 폴더는 직접 생성해줘야 한다.

4. *Zookeeper 먼저 실행** 
```bash
bin/windows/zookeeper-server-start.bat config/zookeeper.properties
```

5. **Kafka 실행**
```bash
bin/windows/kafka-server-start.bat config/server.properties
```

### 📝 배운점 
- Kafka는 `log.dirs` 디렉터리가 잠기거나 잘못되면 무조건 종료됨
- Zookeeper에 남은 `/brokers/ids/0` 정보가 브로커 충돌을 유발할 수 있음
- Kafka/Zookeeper는 항상 정상 종료할 것 (Ctrl + C 또는 shutdown)
- 에러 로그 메시지를 읽으면 문제 해결의 실마리를 찾을 수 있다


### 🤔 회고

처음엔 단순히 경로 문제로 인식하고 `\tmp\kafka-logs` 폴더를 지우고 다시 실행하니 브로커 0번과의 충돌이 있다고 에러가 떴다. 그래서 나는 CMD에서 Zookeeper에 연결해서 브로커 0번을 삭제해주었다.
그걸 여러번 반복하다 그냥 폴더를 다 지워보자해서 했더니 잘 작동되어서 찾아보게 되었고 이런 이유여서 그랬구나를 알 수 있었다.

내가 시행했던 착오들을 정리해보려고 한다.

CMD에서 브로커가 있는지 확인하는 방법은 다음과 같다.

1. Zookeeper Shell 접속

```bash
bin\window\zookeeper-shell.bat localhost:2181
```

이걸로 Zookeeper에 접속하면 아래와 같은 화면이 나온다.

<img src="https://github.com/user-attachments/assets/69a1a7c1-ee84-4a44-9fe3-e33d9dd689fa" />

2. 현재 브로커 확인
```bash
ls /brokers/ids
```
`[]` 은 현재 브로커는 없는 거고 `[0]` 이면 0번 브로커가 실행중이라는 뜻이었다.

3. 브로커 0삭제
```bash
delete /brokers/ids/0
```
삭제 성공하면 Node deleted successfully 이런 메시지 나오고 삭제되었다.
